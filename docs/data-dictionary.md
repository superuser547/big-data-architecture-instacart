# Словарь данных

Все первичные ключи исходных сущностей положительны. Проверки уникальности и
ссылок выполняются до загрузки, а PostgreSQL повторно обеспечивает ключевые
ограничения.

| Схема.Таблица | Поле | Тип | Описание |
|---|---|---|---|
| `core.users` | `user_id` | integer | Уникальный покупатель из заказов |
| `core.departments` | `department_id` | smallint | Идентификатор подразделения |
|  | `department_name` | text | Название подразделения |
| `core.aisles` | `aisle_id` | smallint | Идентификатор товарной группы |
|  | `aisle_name` | text | Название группы |
|  | `department_id` | smallint | Подразделение группы, выведенное из товаров |
| `core.products` | `product_id` | integer | Идентификатор товара |
|  | `product_name` | text | Название товара |
|  | `aisle_id` | smallint | Товарная группа |
| `core.orders` | `order_id` | integer | Идентификатор заказа |
|  | `user_id` | integer | Покупатель |
|  | `eval_set` | varchar(8) | Разделение `prior`, `train` или `test` |
|  | `order_number` | smallint | Порядковый номер заказа покупателя |
|  | `order_dow` | smallint | День недели, 0–6 |
|  | `order_hour_of_day` | smallint | Час заказа, 0–23 |
|  | `days_since_prior_order` | real, nullable | Дни от предыдущего заказа; NULL для первого заказа |
| `core.order_items` | `order_id` | integer | Заказ; часть составного первичного ключа |
|  | `product_id` | integer | Товар; часть составного первичного ключа |
|  | `add_to_cart_order` | smallint | Позиция добавления, уникальна внутри заказа |
|  | `reordered` | boolean | Был ли товар заказан повторно |

`core.order_items` также имеет `UNIQUE (order_id, add_to_cart_order)`. Позиции
из двух исходников объединяются; принадлежность выборке определяется через
`core.orders.eval_set`.
