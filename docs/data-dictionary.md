# Словарь данных

Все первичные ключи исходных сущностей положительны. Проверки уникальности и
ссылок выполняются до загрузки, а PostgreSQL повторно обеспечивает ключевые
ограничения.

| Схема.Таблица | Поле | Тип | Описание |
|---|---|---|---|
| `core.users` | `user_id` | integer | Уникальный покупатель из заказов |
| `core.departments` | `department_id` | smallint | Идентификатор подразделения |
|  | `department_name` | text | Название подразделения |
| `core.aisles` | `aisle_id` | smallint | Идентификатор товарной группы |
|  | `aisle_name` | text | Название группы |
|  | `department_id` | smallint | Подразделение группы, выведенное из товаров |
| `core.products` | `product_id` | integer | Идентификатор товара |
|  | `product_name` | text | Название товара |
|  | `aisle_id` | smallint | Товарная группа |
| `core.orders` | `order_id` | integer | Идентификатор заказа |
|  | `user_id` | integer | Покупатель |
|  | `eval_set` | varchar(8) | Разделение `prior`, `train` или `test` |
|  | `order_number` | smallint | Порядковый номер заказа покупателя |
|  | `order_dow` | smallint | День недели, 0–6 |
|  | `order_hour_of_day` | smallint | Час заказа, 0–23 |
|  | `days_since_prior_order` | real, nullable | Дни от предыдущего заказа; NULL для первого заказа |
| `core.order_items` | `order_id` | integer | Заказ; часть составного первичного ключа |
|  | `product_id` | integer | Товар; часть составного первичного ключа |
|  | `add_to_cart_order` | smallint | Позиция добавления, уникальна внутри заказа |
|  | `reordered` | boolean | Был ли товар заказан повторно |

`core.order_items` также имеет `UNIQUE (order_id, add_to_cart_order)`. Позиции
из двух исходников объединяются; принадлежность выборке определяется через
`core.orders.eval_set`.

## Аналитические витрины

Публичные представления `mart` показывают только последний успешно опубликованный
снимок, соответствующий fingerprint из `ops.active_dataset`. При смене импорта
они возвращают пустую выборку до пересчёта. Служебные таблицы с префиксом `_`
хранят версионированные строки. Ни одна таблица аналитики не ссылается внешним
ключом на `core`, поэтому не препятствует транзакционной пересборке источника.

| Витрина | Гранулярность и основные поля |
|---|---|
| `mart.dataset_overview` | Одна строка; сущности, заказы по eval_set, известные заказы/позиции, числитель и знаменатель повторов, средний размер корзины и доля повторов |
| `mart.order_activity` | eval_set × `order_dow` × `order_hour_of_day`; число заказов, включая test |
| `mart.order_summary` | Один заказ prior/train с известным составом; пользователь, время, basket size, повторные позиции, aisles и departments |
| `mart.category_activity` | eval_set × день/час × размер корзины × department/aisle; числитель и знаменатель для совместной фильтрации времени, категории и размера корзины |
| `mart.department_reorders` | eval_set × department/aisle; позиции, повторные позиции, заказы и покупатели |
| `mart.product_popularity` | eval_set × товар; позиции, повторы, заказы и покупатели с названиями категорий |
| `mart.cart_position_stats` | eval_set × позиция × размер корзины либо department/aisle; позиции, повторы и заказы |
| `mart.customer_features` | Один покупатель; prior-заказы, средняя корзина, доля повторов, средний интервал, уникальные товары и категории |
| `mart.customer_segments` | Один покупатель; `cluster_id` и координаты `pca_1`, `pca_2` |
| `mart.cluster_metrics` | Один k; inertia, silhouette на выборке, размеры кластеров и отметка выбранного k |
| `mart.cluster_profiles` | Один кластер; число покупателей, средние признаки и центр после обратного преобразования |
| `mart.hypothesis_results` | Одна проверка; H0/H1, метод, объём, статистика, p-value, эффект, интервал и JSON-метрики |
| `mart.hypothesis_categories` | Гипотеза × уровень категории × категория × eval_set × позиция; числитель, знаменатель, доля и интервал |
| `mart.hypothesis_pairs` | Парное сравнение позиций; число заказов, discordant-пары, разность долей, bootstrap-интервал, raw/adjusted p-value |

`ops.analytics_runs` регистрирует fingerprint набора, `ingestion_run_id`, время,
статус, параметры, проверки и результаты запуска. `ops.analytics_state` указывает
на актуальные `marts_run_id` и `analysis_run_id`.
